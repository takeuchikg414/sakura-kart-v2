# SAKURA KART — サイト

インバウンド向け公道カートツアーの集客サイト。
デザインは Chispa（ポップな色面・太いディスプレイ書体・流れる帯・傾いたカード）をベースに、
日本のアニメ要素（集中線・網点・コマ枠・擬音・桜吹雪・カートのマスコット）を加えたもの。
構成は競合（kart.st）の掲載項目をすべて網羅している。素の HTML/CSS/JS のみ、ビルド不要。

## ページ
| ファイル | 内容 |
|---|---|
| `index.html` | トップ（LP）。下の「セクション構成」参照 |
| `license.html` | 必要な運転免許の詳しいガイド（4タイプ・IDPの7条件・事前チェック） |
| `terms.html` | 利用規約（20条）＋キャンセルポリシー（`#cancel`）※サンプル文面 |
| `legal.html` | プライバシーポリシー＋特定商取引法に基づく表記（`#tokushoho`）※（未定）を埋める |

## トップのセクション構成
ローディング（信号→よーい、ドン！）→ ヘッダー → Hero（巨大ロゴ＋カート）→ 免許の注意テープ＋流れる帯 →
NEWS／SAKURA KARTとは／選ばれる3つの理由 → 当日の流れ（スクロールで場面と背景色が変わる6場面）→
コース・料金（傾いたカード＋時間帯料金）＋オプション → 車両 → 予約（流れ・注意・他の予約方法＋予約ウィジェット）→
免許 → 保険・キャンセル → 口コミの壁（ドラッグ可）＋SNS → FAQ（11問）→ アクセス＋道順 → 会社情報 →
フッター（レシート風チケット）＋右下の相談・予約ボタン＋スタッフ相談ポップアップ

## 翻訳（英語がデフォルト、`?lang=ja` で日本語）
- 短い文言：英語を要素に書き、日本語を `data-ja="…"` に書く
- 長い文章：`<div class="en">…</div><div class="ja">…</div>` と並べる
- 属性：`data-ja-aria-label` など

## 素材・情報が届いたら差し替える場所
- `.ph` の要素（`data-label` の付いた色付きの枠）がすべて仮画像 → `<img src="images/xxx.jpg" alt="...">` に置き換える
- 連絡先・SNS・営業時間 → `js/config.js` の `contact`（全ページに自動で反映）
- 料金・コース・時間帯・保険料 → `js/config.js`
- 住所・最寄駅・会社情報・特商法の（未定）→ 各HTMLに直接
- 口コミ（サンプル）、保険の補償額、キャンセル料率、利用規約 → 実際の内容に合わせて修正（規約は専門家の確認を推奨）

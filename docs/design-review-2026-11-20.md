# デザインレビュー：重なり・可読性（2026-11-20）

対象：トップ（index.html）PC 1280px／スマホ 375px
前提（CEO指示）：「重なってもいいが、見にくいのはNG」「ローディングのロゴはなし（元のカートに戻す）」

---

## 1. デザイナーの指摘

判断基準：**重ねてよいのは「装飾×画像」まで。文字の上に文字・画像・ステッカーを重ねない。** 1か所に重なる層は最大2つまで。

| # | 場所 | 症状 | 重さ |
|---|---|---|---|
| D1 | ヒーロー：巨大な「Sakura」 | ロゴが文字の中央を隠し「Sa…ra」としか読めない。ブランド名が読めない | 高 |
| D2 | ヒーロー：「ブォン!!」 | 巨大文字＋ロゴの上に乗り、3層が重なっている | 高 |
| D3 | ヒーロー：「REAL STREETS OF TOKYO」 | 巨大文字とロゴの両方にかぶさり、どちらも読みにくい | 高 |
| D4 | ヒーロー：小さいカート | 見出し「Be the hero…」にタイヤが接触。スマホではロゴにも重なる | 高 |
| D5 | ヒーロー：PCの1画面目 | ロゴが大きく、予約ボタンが1画面目に入らない | 中 |
| D6 | ヒーロー（スマホ） | タグ・擬音・バッジ・カート・巨大文字がロゴ周りに密集し、何が主役か分からない | 高 |
| D7 | 流れる帯（2本） | 赤い帯が緑の帯の文字の下半分を隠している（「Shibuya Crossing」が読めない） | 高 |
| D8 | 当日の流れ | 説明文が長いと、下の時刻ボタン（−30 / −20…）に文字がぶつかる | 中 |
| D9 | コース・料金 | 背景の巨大「Rides」がカードに切られて断片だけ見え、ノイズになっている | 中 |
| D10 | コース・料金（スマホ） | カードの傾き（−5°）が大きく、1枚で画面を占めるスマホでは文字が斜めで読みにくい | 中 |
| D11 | 口コミの壁（タブレット幅） | 写真の幅が固定なので、画面が狭いとカード同士が重なって文字が隠れる | 中 |
| D12 | 右下の固定ボタン（スマホ） | 1画面目から表示され、ボタンや本文を隠す。ページ最下部の内容も隠れる | 中 |

問題なし（意図した重なりとして維持）：料金カードの「No.1」ステッカー、写真枠の「ドキドキ」、口コミの写真の傾き、フッターのチケットとカート

## 2. ディレクターの指示（エンジニア向け）

| # | 対応方針 | 受け入れ基準 |
|---|---|---|
| D1 | ロゴを巨大文字の**下側**に配置。ロゴが文字に重なるのは文字の下端 1/4 以内 | PC・スマホとも「Sakura」6文字が読める |
| D2 | 「ブォン!!」はロゴから外し、小さいカートのそばへ（カートの擬音として）。スマホでは非表示 | 擬音が文字やロゴに重ならない |
| D3 | タグは浮かせず、見出しの上の“ラベル”として配置（少し傾けたステッカーのまま） | タグが他の要素に重ならない |
| D4 | カートはロゴの右側に置く（PC 1024px以上のみ）。タブレット・スマホでは非表示 | カートが文字に触れない |
| D5 | PC（1200px以上）はキャッチコピーを左下、ロゴを中央に配置し、1画面目に予約ボタンを入れる | 1280×800 で「BOOK A RIDE」が見える |
| D6 | スマホのヒーローは「巨大文字 → ロゴ（＋営業バッジ）→ ラベル＋見出し → ボタン」の縦1列に整理 | 375px で要素同士が重ならない（バッジのみロゴの縁に少し重ねて可） |
| D7 | 2本の帯は文字が隠れない間隔に。端でかすかに交差する程度に角度を調整 | 両方の帯の文字が全部読める |
| D8 | 場面の切り替えは重ね置き（grid）にし、高さを一番長い場面に合わせる | 日英どちらも説明文とボタンが重ならない |
| D9 | 背景の巨大「Rides」は“読ませない地紋”として、背景色に近いトーンに落とす | カードの間から見えても気にならない |
| D10 | スマホでは料金カードの傾きを ±1.5° 以内にし、段違いもやめる | 斜めの文字が気にならない |
| D11 | 1024px 未満は口コミをグリッド表示（タブレット3列・スマホ2列）にする | どの幅でもカードの文字が隠れない |
| D12 | 固定ボタンはヒーローを過ぎてから表示。スマホでは小さくし、ページ末尾に余白を足す | ヒーロー内のボタンを隠さない、フッターの文字が隠れない |
| — | ローディングはロゴをやめ、元の走るカートに戻す | ✅ 対応済み |

優先順：D1〜D7（高）→ D8〜D12（中）

## 3. 実装結果（エンジニア）
D1〜D12 すべて対応済み。PC 1280×800・タブレット 768×1024・スマホ 375×812 で基準を確認。
- 追加対応：営業バッジがロゴ内の「KART」に重なっていたため、PCはロゴの右側、スマホはロゴの右上（イラスト部分）へ移動
- 1024px未満では口コミのドラッグを無効化（グリッド表示のため）
確認：PC 1280×800 とスマホ 375×812 のスクリーンショットで、上の基準を1つずつ確認する。
